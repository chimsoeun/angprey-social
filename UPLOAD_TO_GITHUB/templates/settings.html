របៀបតភ្ជាប់ Google Sheet Online៖

  1. បើក Google Sheet ថ្មីមួយនៅលើ Google Drive
  2. ចុចម៉ឺនុយ Extensions → Apps Script
  3. ចម្លងកូដខាងឆ្វេងនេះ យកទៅបិទភ្ជាប់ (Paste) ក្នុង Apps Script
  4. ចុចប៊ូតុង Deploy → New deployment
  5. ជ្រើសរើសប្រភេទ Web app
  6. ត្រង់ Who has access ជ្រើសរើស Anyone
  7. ចុច Deploy → Review permissions → Allow
  8. ចម្លង Web app URL យកមកបិទភ្ជាប់ក្នុងប្រអប់ខាងឆ្វេង រួចចុច រក្សាទុក!
